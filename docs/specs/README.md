# Specs

Une spec par fonctionnalité, rédigée avec `_gabarit.md`, validée par Mathieu avant tout test ou code.

**Depuis le 2026-11-24, une spec naît d'une issue `Feature` (ou `Epic`)** : fichier `issue-<N>-<sujet>.md`, cité « spec #N »,
branche `feature/<N>-<sujet>`. Le reste à faire, l'ordre et les versions se lisent dans les issues et les milestones de GitHub
(`docs/issues.md`, Planification). Le statut d'une spec est dans son en-tête.

Les specs d'avant cette date gardent leur numéro à trois chiffres (`000` à `092`), qui n'est pas un numéro d'issue.
Leur index et leurs jalons sont dans [`PLAN.md`](PLAN.md), archivé.

Les sujets reportés ou transverses sont suivis dans les issues GitHub au label `question ouverte` (`docs/issues.md`).
