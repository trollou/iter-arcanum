# Règles pour l'internationalisation

Détails : `docs/decisions/0003-internationalisation.md`.

- Un fichier JSON par langue dans `assets/i18n/`, en UTF-8. `fr.json` est la référence.
- Clés hiérarchiques en anglais (`card.march.name`), paramètres nommés entre accolades (`{amount}`).
- Ajouter une clé = l'ajouter dans **toutes** les langues dans la même modification.
- Une clé manquante s'affiche `⟦clé⟧` et est journalisée, sans planter.
- Tests obligatoires : mêmes clés et mêmes paramètres dans toutes les langues ; toute clé utilisée par le code existe dans `fr.json`.
- Les termes de jeu suivent `docs/glossaire.md`.
